# שכבת תנועה וחומרים (גרסה 2, 9.10.2026)

שכבה אחת של CSS ושני קטעי JS קטנים, בלי שינוי בתוכן, במזהים או במפתחות השמירה. היא מבוססת על עקרונות apple-design: משוב מיידי בלחיצה, החזרה רכה, אלמנטים צפים מעומעמים, כניסה עקבית של הסרגל וההודעה, חלונות שנפתחים בהדרגה, מעבר רך בין רקע בהיר לכהה, והתאמה להעדפות נגישות של המכשיר.

**היא כבר בתוך הקבצים.** היא מוטמעת בשתי האפליקציות החיות (תלמיד ומורה), בעותקים שבתיקיית האפליקציות ובשבלונות גרסה 4. שבוע חדש שנבנה מהשבלונות מקבל אותה בלי שום הדבקה. את המסמך הזה צריך רק כדי לתקן או לעדכן את השכבה, ובמקרה כזה מעדכנים אותה בכל המקומות יחד: האפליקציות החיות, העותקים והשבלונות.

## מה השתנה מהגרסה הראשונה

- בגרסה הראשונה הבלוק הבסיסי לא נכנס בפועל לקבצים החיים (פרסום מאוחר יותר איבד אותו), ולכן הנפשת הכיווץ של הלחצנים לא נראתה. עכשיו הכול בפנים, ונבדק בדפדפן: לחיצה מקטינה לחצן ל-0.94 מגודלו, והוא חוזר ברכות.
- נוסף כלל `[hidden] { display: none !important; }`. בצופה שלא מוסיף אותו, אלמנט שמוגדר לו `display: grid` נשאר פתוח למרות `hidden`. כך מפת המסע של המורה הופיעה פתוחה.
- חלונות העזרה (`details`) נפתחים וננעלים בהדרגה. שימו לב: זה דורש `interpolate-size`, שנתמך בדפדפני Chromium. בשאר הדפדפנים החלון פשוט נפתח מיד.
- תוכן השיעור של התלמיד נכנס בהדרגה בכל מעבר בין שיעורים (בלוק נפרד, לתלמיד בלבד).
- כרטיס "השיעור הנוכחי" של התלמיד הוסר, ועם הכרטיס תווית "כעת" בלשוניות.

ההשפעה עדינה בכוונה. רואים אותה בעיקר בלחיצה על לחצנים, בפתיחת חלונות, בסרגל הסיור ובהודעות. כדי לבדוק: להחזיק את לחצן העכבר על לחצן בלי לשחרר, והוא אמור להתכווץ מיד.

## בלוק CSS בסיסי (תלמיד ומורה)

## JS (תלמיד ומורה)

מוסיפים מיד אחרי `"use strict";`. הקטע הראשון מאפשר משוב `:active` ב-iOS, והשני עוטף את החלפת הרקע במעבר רך.

```js
document.addEventListener("touchstart", function () { }, { passive: true });
function withFade(fn) {
  try {
    if (document.startViewTransition && !window.matchMedia("(prefers-reduced-motion: reduce)").matches) { document.startViewTransition(fn); return; }
  } catch (e) { }
  fn();
}
// בלחיצה על כפתור הרקע: withFade(applyView);
```

## כללים לעריכה

- הכלל `.step:active:not(:has(:active))` חשוב: `:active` חל גם על האבות של האלמנט הנלחץ, ובלי התנאי כל צעד היה מתכווץ כשלוחצים על כפתור שבתוכו.
- הכלל `[hidden]` נשאר גם אם הפלטפורמה מוסיפה אותו בעצמה. אל תמחקו אותו.
- בדיקה אחרי כל שינוי בשכבה: `check_week.py`, ואז דפדפן בבהיר ובכהה, ובמחשב ובטלפון.
