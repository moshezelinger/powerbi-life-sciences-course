# הכנה למבחן המעשי ב-Power BI

עודכן: 3.11.2026.

## מה יש כאן

שני דפי תרגול פתוחים לתלמידים, כל אחד בקובץ נפרד:

- **תרגול Portal:** ניקוי לפי כללי החוקרים, Slicer, כרטיס, גרף עמודות וטבלת סבבים בעמוד נפרד. המין העיקרי הוא PE (2017 מול 2023), ובמשימה העצמאית PB (2017 מול 2024). קישור קצר: `practice/portal.html`.
- **תרגול BRFSS:** שלושה סינונים, איחוד שמות קבוצות ההשכלה, גרף קווים, Slicer וטבלה. המדינה העיקרית היא קנזס, ובמשימה העצמאית אינדיאנה. יש גם בונוס בסגנון שיעור 6. קישור קצר: `practice/brfss.html`.

## איך בנויים הדפים

- המשימות מגדירות מה צריך להתקבל, בלי הוראות לחיצה. לכל משימה בחלק א יש שאלה לתכנון ובדיקה של התוצאה.
- השאלות הסגורות נבדקות בדף ומקבלות ניקוד. כל בדיקה נרשמת בסיכום שמגישים, כולל מספר הניסיונות.
- שאלת "רצף העבודה" מבקשת מהתלמידים לבחור, לכל שלב, כפתור או פקודה מתוך מאגר. במאגר יש פקודות שנלמדו בשיעורים 1 עד 6, וחלקן מסיחים.
- הסיכום שמדביקים במודל כולל JSON עם מזהה לכל סעיף, כמו בשיעור 4.

## המבחן

המבחן (שני טורים, 60 דקות) והמחוון נמצאים רק בקישורים פרטיים אצל המורה, ולא בריפו הציבורי.

## מה נבדק ומה עוד לא

- כל המספרים בתרגולים חושבו מחדש מ-Portal_rodents_2016_2026.csv ומ-BRFSS_PA (60,060 שורות).
- הדפים נבדקו בדפדפן: מחשב וטלפון, רקע בהיר וכהה, שמירה אחרי רענון, בדיקת תשובות והעתקת הסיכום.
- הזמנים (כ-40 דקות לכל תרגול) הם הערכה. עוד לא נבדק כמה זמן לוקח לבצע את המשימות ב-Power BI במחשבי הכיתה.
