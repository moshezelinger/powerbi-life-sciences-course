לא מוצאים כפתור ב-Power BI? לחצו בדוח על שם הכפתור (הוא מופיע במסגרת אפורה). השם יועתק, ותופיע הודעה שאומרת איפה הכפתור נמצא.

קבצי הנתונים להורדה

כל קובץ מורידים רק כשהצעדים בשיעור מבקשים. הקובץ יורד לתיקייה Downloads (הורדות). משם מעבירים אותו לתיקייה data שלכם, ולא משנים את השם שלו.

התיקייה שלכם

כל השבוע עובדים באותה תיקייה: Documents\PBI_Course\Cohen_Noa

במקום Cohen_Noa כתבו את השם שלכם באנגלית, בלי רווחים. כך גם בשמות של קובצי Power BI.

  • בתוכה שתי תיקיות: data לקובצי הנתונים, ו-work לקובצי Power BI.
  • בכל שיעור פותחים את הקובץ שכתוב בצעדים, ושומרים מיד בשם חדש: L01, L02 וכן הלאה. כך תמיד יש גרסה קודמת.
  • בווינדוס בעברית התיקייה Documents נקראת מסמכים.
  • אל תזיזו את הקבצים שב-data ואל תשנו את השמות שלהם. Power BI שומר את המיקום המדויק של כל קובץ, ואם קובץ זז, Power BI לא ימצא אותו בפעם הבאה.
מילים שכדאי להכיר
  • שורה (רשומה): פריט מידע אחד בקובץ. מה בדיוק מתועד בשורה, בודקים בכל מאגר מחדש.
  • עמודה (משתנה): סוג מידע שנרשם בכל שורה, כמו שנה או משקל.
  • מזהה: עמודה שתפקידה לזהות, כמו recordID. אין טעם לחבר מזהים.
  • חלקה: שטח מגודר של 50 על 50 מטרים. יש 24 חלקות, ובכל אחת 49 מלכודות.
  • סבב לכידה: פעם בחודש, סמוך למולד הירח, החוקרים מציבים מלכודות בחלקות במשך שני לילות. כל ערך חיובי של period הוא סבב לכידה אחד.
  • לכידה: פעם אחת שבה חיה נמצאה במלכודת.
  • פרט: חיה אחת מסוימת. בקובץ מזהים אותה לפי העמודה id.
  • מאמץ דגימה: כמה סבבי לכידה נערכו בתקופה מסוימת.
  • השוואה הוגנת: השוואה בין שנים שמתחשבת במאמץ הדגימה.
  • Power Query: החלון שבו מנקים את הנתונים לפני שהם נכנסים לדוח.
  • שאילתה (Query): טבלה ב-Power Query, יחד עם רשימת הצעדים שבוצעו כדי ליצור אותה.
  • רשימת הצעדים (Applied Steps): ה"מתכון" של Power Query. כל צעד שביצעתם נרשם ברשימה שבצד ימין של החלון. הרשימה נשמרת, ובכל רענון Power BI מבצע מחדש את כל הצעדים שבה, לפי הסדר.
  • רענון (Refresh): Power BI קורא שוב את קובץ הנתונים, ומבצע מחדש את כל הצעדים שברשימה.
איפה הכפתור? כל הכפתורים של השבוע

לחיצה על שם של כפתור במסגרת אפורה, בתוך הצעדים, מעתיקה אותו ואומרת איפה הוא נמצא. כאן כל המיקומים במקום אחד. הם מתאימים לממשק באנגלית.

בחלון Power BI

  • Blank report: במסך הפתיחה, כשפותחים את Power BI.
  • Get data: בסרגל העליון, בלשונית Home.
  • Excel workbook: ברשימה שנפתחת מתחת ל-Get data.
  • Load ו-Transform data, אחרי שבוחרים קובץ: בתחתית החלון שמציג את תוכן הקובץ.
  • Report view, Table view ו-Model view: שלושת הסמלים העליונים בפס האנכי בצד שמאל של החלון.
  • מספר השורות: ב-Table view, בשורת המצב שבתחתית החלון.
  • Card, Table, Slicer, Clustered column chart ו-Line chart: בחלונית Visualizations שבצד ימין.
  • רשימת העמודות: בחלונית Data שבצד ימין, ליד Visualizations.
  • Count, Average, Count (Distinct) ו-Don't summarize: בחץ הקטן שליד שם העמודה, באזור השדות של הגרף או הטבלה בחלונית Visualizations.
  • Format visual (סמל המברשת): בחלונית Visualizations, כשהגרף מסומן. בראש החלונית יש תיבת חיפוש.
  • Display units: בתוך Format visual. הכי מהר: מקלידים Display units בתיבת החיפוש של Format visual.
  • X-axis ואחריו Type: בתוך Format visual, כשגרף העמודות מסומן.
  • Legend: באזור השדות של גרף הקווים, בחלונית Visualizations.
  • עמוד חדש (+): בתחתית החלון, ליד שמות העמודים. לחיצה כפולה על שם של עמוד מאפשרת לשנות את השם.
  • Column tools ו-Summarization: ב-Table view לוחצים על עמודה, ובסרגל העליון נפתחת הלשונית Column tools.
  • Transform data: בסרגל העליון, בלשונית Home. פותח את Power Query.
  • Data source settings: בחץ הקטן של הכפתור Transform data.
  • Change Source: בתחתית החלון Data source settings.
  • Apply changes: בפס צהוב שמופיע מתחת לסרגל העליון אחרי החלפת קובץ.
  • Refresh: בסרגל העליון, בלשונית Home.
  • Save as: בתפריט File.
  • חיפוש: תיבת החיפוש בראש החלון. מקלידים שם של פקודה, למשל Get data.

בחלון Power Query

  • Applied Steps: בחלונית Query Settings שבצד ימין. ה-X שליד צעד מוחק אותו.
  • Queries, רשימת השאילתות: בצד שמאל של החלון. לחיצה ימנית על שאילתה פותחת תפריט, ובו Duplicate.
  • Column quality, Column distribution ו-Column profile: בלשונית View, בקבוצה Data Preview.
  • Column profiling based on top 1000 rows: בשורת המצב שבתחתית החלון, משמאל. לחיצה עליו מאפשרת לבחור entire data set.
  • Number Filters ו-Remove Empty: בחץ שבכותרת העמודה.
  • Load more: בתחתית הרשימה שנפתחת מהחץ בכותרת העמודה. לוחצים עליו כשערך שמחפשים לא מופיע ברשימה.
  • Choose Columns: בלשונית Home, בקבוצה Manage Columns.
  • Replace Values: בלשונית Home או בלשונית Transform, אחרי שלוחצים על העמודה. Advanced options נמצא בתוך החלון שנפתח.
  • שינוי שם של עמודה: לחיצה כפולה על כותרת העמודה.
  • סוג הנתונים, למשל Decimal Number: בסמל שמשמאל לשם העמודה, בכותרת (ABC, 123 או 1.2).
  • Close & Apply: בלשונית Home, הכפתור הראשון משמאל.

עזרה עם צילומי מסך, באנגלית: חלון Power BI, הסרגל העליון ותיבת החיפוש, חלון Power Query.

המכרסמים במחקר: שמות, תמונות וקישורים

בקובץ כל מין מופיע כקוד של שתי אותיות. השמות בעברית הם תרגום חופשי של השם האנגלי. כל קישור נפתח בלשונית חדשה: ויקיפדיה באנגלית, ותמונות של המין בוויקישיתוף.

הסימונים והתשובות נשמרים רק בדפדפן הזה, ולא נשלחים לאף אחד. את התוצר מגישים במודל.
