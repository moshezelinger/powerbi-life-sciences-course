# תבניות דוחות לבדיקת עבודות

הסקריפטים שבונים את קובצי ה-Excel וה-Word של הבדיקה, ואת המחוון לקריאה. ההסבר המלא נמצא ב"מערכת/מדריך בדיקת עבודות.md".

| קובץ | מה הוא עושה |
| --- | --- |
| extract.py | מחלץ טקסט ותמונות מקובצי docx של ההגשות |
| grading\_data.py | נתוני הבדיקה: ניקוד והערות לכל תלמיד. בריפו יש רק דוגמה עם שמות בדויים |
| build\_reports.py | Excel ו-Word לתרגילים 1-2, קובץ לכל קבוצה |
| build\_l3.py | משוב Word לתרגיל 3, וגיליונות "שיעור 3" ו"סיכום הגשות" בקובץ ה-Excel |
| rubric\_data.py, build\_rubric.py | המחוון לקריאה, ב-Word וב-Excel |

שימוש: מעתיקים את התיקייה למקום מקומי, ממלאים את grading\_data.py בנתוני הכיתה, ומריצים `python3 build_l3.py תיקיית_פלט` (הוא מריץ גם את build\_reports.py). את המחוון לקריאה בונים עם `python3 build_rubric.py תיקיית_פלט`.

נתוני הכיתה והקבצים שנוצרים לא עולים לריפו.
