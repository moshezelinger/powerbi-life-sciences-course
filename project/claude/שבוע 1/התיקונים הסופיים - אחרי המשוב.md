## 3. דוח הלמידה לתלמיד

### ראש העמוד והעזרה

- [x] **ת1. הפתיח** ✅
    - זה דוח הלמידה שלכם לשבוע הראשון. לכל שיעור יש כאן מטרה, צעדים שתסמנו אחרי שתבצעו אותם, שאלות, ומה מגישים במודל בסוף השיעור. לא מוצאים כפתור ב-Power BI? לחצו כאן בדוח על שם הכפתור (הוא מופיע במסגרת אפורה). השם יועתק, ותופיע הודעה שאומרת איפה הכפתור נמצא.
- [x] **ת2. "התיקייה שלכם"** ✅
    - אל תזיזו את הקבצים שב-data ואל תשנו את השמות שלהם. Power BI שומר את המיקום המדויק של כל קובץ, ואם קובץ זז, Power BI לא ימצא אותו בפעם הבאה.
- [x] **ת3. "מילים שכדאי להכיר"** ✅, עם התאמה לכלל מ12
    - **שורה (רשומה):** פריט מידע אחד בקובץ. מה בדיוק מתועד בשורה, בודקים בכל מאגר מחדש.
    - **עמודה (משתנה)** ו**מזהה:** בלי שינוי.
    - **חלקה:** שטח מגודר של 50 על 50 מטרים. יש 24 חלקות, ובכל אחת 49 מלכודות.
    - **סבב לכידה:** פעם בחודש, סמוך למולד הירח, החוקרים מציבים מלכודות בחלקות במשך שני לילות. כל ערך חיובי של period הוא סבב לכידה אחד.
    - **לכידה:** פעם אחת שבה חיה נמצאה במלכודת.
    - **פרט:** חיה אחת מסוימת. בקובץ מזהים אותה לפי העמודה id.
    - **מאמץ דגימה:** כמה סבבי לכידה נערכו בתקופה מסוימת.
    - **השוואה הוגנת:** השוואה בין שנים שמתחשבת במאמץ הדגימה.
    - **Power Query:** בלי שינוי.
    - **שאילתה (Query):** טבלה ב-Power Query, יחד עם רשימת הצעדים שבוצעו כדי ליצור אותה.
    - **רשימת הצעדים (Applied Steps):** ה"מתכון" של Power Query. כל צעד שביצעתם נרשם ברשימה שבצד ימין של החלון. הרשימה נשמרת, ובכל רענון Power BI מבצע מחדש את כל הצעדים שבה, לפי הסדר.
    - **רענון (Refresh):** Power BI קורא שוב את קובץ הנתונים, ומבצע מחדש את כל הצעדים שברשימה.

- [x] **ת10. המטרה וההקדמה** ✅, עם "מתכון" (מ3)
    - מטרה: היום תנקו את הנתונים ב-Power Query לפי שני כללים שכתבו החוקרים. כל סינון שתעשו יישמר כצעד ברשימת הצעדים (Applied Steps), ה"מתכון" של Power Query.
    - הקדמה: החוקרים כתבו בתיעוד של המחקר שני כללים. 1. שורה שבה period שלילי נרשמה מחוץ לסבבים הקבועים, ולכן לא מנתחים אותה. 2. שורה בלי species מתעדת חלקה שלא נלכדה בה אף חיה, או חלקה שבאותו סבב לא הציבו בה מלכודות, ולכן היא לא לכידה. היום תסננו את הנתונים לפי שני הכללים האלה. הקובץ בתיקייה data לא ישתנה: הסינון חל רק על הנתונים שנטענים ל-Power BI.
- [x] **ת11. צעד 2** ✅, עם תיבת הסבר (מ13)
    - צעד: לחצו על Transform data (בסרגל העליון, בלשונית Home). ייפתח חלון חדש: Power Query Editor.
    - מה אמור להופיע: בצד ימין, ברשימת הצעדים (Applied Steps), כבר יש שלושה צעדים: Source, Promoted Headers ו-Changed Type.
    - למה עושים את זה? ב-Power Query מנקים את הנתונים לפני שהם נכנסים לדוח. את שלושת הצעדים הראשונים Power BI הוסיף כשטענתם את הקובץ: Source קורא את הקובץ, Promoted Headers הופך את השורה הראשונה לשמות העמודות, ו-Changed Type קובע לכל עמודה סוג, למשל מספר או טקסט.

## 6. לקט כפתורים: איפה כל כפתור ב-Power BI ✅

- [x] **נ1.** חלון שנפתח בלחיצה, "איפה הכפתור?": בדוח הלמידה ליד "מילים שכדאי להכיר", ובמסע ההכנה בתוך "על הנתונים".
- [x] **נ2.** ההודעה בלחיצה על שם של כפתור אומרת גם איפה הוא. למשל: "הועתק: Get data. הכפתור נמצא בסרגל העליון, בלשונית Home."
- [x] **נ3.** קישורים לדפי עזרה עם צילומי מסך (Microsoft Learn, באנגלית): [Use Report view in Power BI Desktop](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-report-view), [Use the ribbon in Power BI Desktop](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-ribbon), [Use Power Query to transform data](https://learn.microsoft.com/en-us/power-query/power-query-ui).
- [x] **נ4. חלון Power BI**
    - **Blank report:** במסך הפתיחה, כשפותחים את Power BI.
    - **Get data:** בסרגל העליון, בלשונית Home.
    - **Text/CSV:** ברשימה שנפתחת מתחת ל-Get data.
    - **Load ו-Transform data, אחרי שבוחרים קובץ:** בתחתית החלון שמציג את תוכן הקובץ.
    - **Report view, Table view ו-Model view:** שלושת הסמלים העליונים בפס האנכי בצד שמאל של החלון.
    - **מספר השורות:** ב-Table view, בשורת המצב שבתחתית החלון.
    - **Card, Table, Slicer, Clustered column chart ו-Line chart:** בחלונית Visualizations שבצד ימין.
    - **רשימת העמודות:** בחלונית Data שבצד ימין, ליד Visualizations.
    - **Count, Average ו-Count (Distinct):** בחץ הקטן שליד שם העמודה, באזור השדות של הגרף בחלונית Visualizations.
    - **Format visual (סמל המברשת):** בחלונית Visualizations, כשהגרף מסומן. בראש החלונית יש תיבת חיפוש.
    - **Display units:** בתוך Format visual. הכי מהר: מקלידים Display units בתיבת החיפוש של Format visual.
    - **X-axis ואחריו Type:** בתוך Format visual, כשגרף העמודות מסומן.
    - **Legend:** באזור השדות של גרף הקווים, בחלונית Visualizations.
    - **עמוד חדש (+):** בתחתית החלון, ליד שמות העמודים. לחיצה כפולה על שם של עמוד מאפשרת לשנות את השם.
    - **Column tools ו-Summarization:** ב-Table view לוחצים על עמודה, ובסרגל העליון נפתחת הלשונית Column tools.
    - **Transform data:** בסרגל העליון, בלשונית Home. פותח את Power Query.
    - **Data source settings:** בחץ הקטן של הכפתור Transform data.
    - **Change Source:** בתחתית החלון Data source settings.
    - **Apply changes:** בפס צהוב שמופיע מתחת לסרגל העליון אחרי החלפת קובץ.
    - **Refresh:** בסרגל העליון, בלשונית Home.
    - **Save as:** בתפריט File.
    - **חיפוש:** תיבת החיפוש בראש החלון. מקלידים שם של פקודה, למשל Get data.
- [x] **נ5. חלון Power Query**
    - **Applied Steps:** בחלונית Query Settings שבצד ימין. ה-X שליד צעד מוחק אותו.
    - **Queries, רשימת השאילתות:** בצד שמאל של החלון. לחיצה ימנית על שאילתה פותחת תפריט, ובו Duplicate.
    - **Column quality, Column distribution ו-Column profile:** בלשונית View, בקבוצה Data Preview.
    - **Column profiling based on top 1000 rows:** בשורת המצב שבתחתית החלון, משמאל. לחיצה עליו מאפשרת לבחור entire data set.
    - **Number Filters ו-Remove Empty:** בחץ שבכותרת העמודה.
    - **Choose Columns:** בלשונית Home, בקבוצה Manage Columns.
    - **Replace Values:** בלשונית Home או בלשונית Transform. Advanced options נמצא בתוך החלון שנפתח.
    - **שינוי שם של עמודה:** לחיצה כפולה על כותרת העמודה.
    - **סוג הנתונים, למשל Decimal Number:** בסמל שמשמאל לשם העמודה, בכותרת (ABC, 123 או 1.2).
    - **Close & Apply:** בלשונית Home, הכפתור הראשון משמאל.

## 7. למה הנתונים חשובים, ומה הרעיון של כל שיעור ✅

- [x] **ח1. Portal, למורה, באזור "על הנתונים"**

    - שיעור 1: לפני שסופרים שורות, בודקים מה כל שורה מייצגת. השאלה הזו תחזור בכל מאגר: ב-Portal, אחרי הניקוי, שורה היא לכידה ולא חיה, וב-BRFSS שורה היא אחוז של קבוצה ולא אדם.

    - שיעור 3: מספר הלכידות תלוי גם במאמץ הדגימה. משווים בצורה הוגנת אחרי נרמול (ממוצע לכידות בסבב), ובודקים מה עוד היה שונה בין השנים, למשל העונה.

    - שיעור 6: גרף הוא גם כלי לבדיקת איכות הנתונים. דפוס בגרף יכול לנבוע מהשאלון, ולכן משווים בין שנים מאותו סוג, למשל רק שנים אי-זוגיות.
    - שיעור 7: זו אוטומציה: מתכון שנבנה פעם אחת עובד גם על נתונים חדשים. לכן מנקים בעזרת צעדים ב-Power Query, ולא בתיקון ידני של הקובץ.
