תיבת הערה בתוך מסמך הכנה, דוח או שקף. שלוש וריאציות: `tip` (תכלת, "טיפ למורה"), `watch` (צהוב, "שימו לב") ו-`question` (כהה, "שאלה לדיון").

**מה לספק:** תווית קצרה ופסקה של עד שלושה משפטים.

**כללים:** תיבה אחת לכל מסך או עמוד בדרך כלל. הסוג מופיע במילה בתווית, לא רק בצבע. בלי גבול צבעוני בצד התיבה.
