**כללים:** כותרות פרק ב-`heading`, שמות שלבים ב-`subheading`. מספר השלב בעיגול `brand-yellow` עם `on-yellow`. סכום הזמנים שווה למשך השיעור. רוחב מסמך עד 820px.
