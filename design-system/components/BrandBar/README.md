סרגל עליון וכרזה למסמכים ולאתרים של המגמה. הסרגל נושא את הלוגו `logo-primary.png` בגובה 64px וקו תחתון בצבע `brand-yellow` בעובי 3px.

**מה לספק:** כותרת המסמך ושורת מטא (כיתה, יחידה, תאריך) משמאל.

**כללים:** הלוגו תמיד על `surface` או `surface-soft`, לא על תמונה. בערכה הכהה אותו קובץ לוגו עובד על `surface`. אל תמתחו ואל תצבעו מחדש. הכרזה (`da-banner`) משמשת רק בראש עמוד הבית.
