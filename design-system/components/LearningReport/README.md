תבנית לדוח למידה של כיתה או תלמיד. סדר קבוע: כותרת עם לוגו, כרטיסי מדד, גרף עמודות אופקי לפי מיומנות, טבלת משימות עם תגיות מצב, תיבת המלצה.

**מה לספק:** נתונים אמיתיים בלבד, עם מקור וגודל מדגם ב-`caption` מתחת לכל גרף.

**כללים:** סדר הצבעים בגרף: `brand-blue`, `brand-gray`, `brand-yellow`, כמו עמודות הלוגו. כל עמודה נושאת ערך כתוב וגבול, כי התכלת והצהוב על רקע לבן לא מגיעים ל-3:1. מצב משימה תמיד במילה ובסימן. מספרים בטבלה מיושרים לשמאל ונקראים משמאל לימין.
