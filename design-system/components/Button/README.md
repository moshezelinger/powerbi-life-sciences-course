כפתור פעולה. `da-btn--primary` (צהוב, טקסט `on-yellow`) לפעולה אחת ראשית בכל מסך. `da-btn--blue` לפעולה משנית חשובה. `da-btn--secondary` (מסגרת `border-strong`) לפעולות עזר.

**מה לספק:** תווית קצרה של עד ארבע מילים, בפועל ("פתיחת המצגת"), לא "לחץ כאן".

**כללים:** פוקוס מקלדת מקבל טבעת `focus-ring` בעובי 3px. לא שני כפתורים ראשיים זה ליד זה.
