# שבלונה כללית לבניית קורסים בעזרת AI

זוהי **מסגרת עבודה ניתנת להעתקה** עבור מורים ומפתחי קורסים. היא נולדה מתוך בניית קורס Power BI על נתוני מדעי החיים, הבריאות והסביבה, אך אינה מיועדת רק ל-Power BI.

**[פתיחת מסמך ההנחיות — COURSE_BUILDING_SYSTEM.md](COURSE_BUILDING_SYSTEM.md)**

## הקשר לריפו

הריפו המרכזי הוא קודם כול **use case מתפתח**: קורס Power BI שמתקיים בכיתה ומשתנה בעקבות ההוראה. מערכת הבנייה שלו, השבלונות הטכניות, הסקילים והתוצרים נמצאים במקומם בתיקיות `project/`, `skills/` ו-`design-system/`.

התיקייה הנוכחית שונה: היא מחלצת מתוך ההתנסות עקרונות **כלליים** לתכנון קורסים באמצעות AI: חלוקת אחריות בין מורה למודל, נקודות אישור קצרות, אבטיפוס לפני הרחבה, בקרת איכות ולמידה מהכיתה.

**זו שבלונה ניסיונית ומתפתחת, לא תהליך גנרי שכבר תוקף בכל תחומי הדעת.**

## איך משתמשים בקורס אחר

1. העתק את `COURSE_BUILDING_SYSTEM.md` לשורש פרויקט הקורס החדש.
2. מלא את טבלת האתחול שבסעיף 3 והפנה לסילבוס, לתוצרים וליומן ההוראה המקומיים.
3. השתמש בהנחיות כדי לתכנן את מפת הקורס, לבנות יחידות בהדרגה, לעצור רק להחלטות משמעותיות ולבדוק תוצרים.
4. הוסף לפי הצורך Skill פדגוגי או מקצועי משלך. אין צורך להעתיק את הקוד, מאגרי הנתונים או הסקילים הספציפיים ל-Power BI.

## מה השבלונה אינה כוללת

- סילבוס מוכן, תכנים מקצועיים או נתונים לקורס חדש.
- אפליקציות ה-HTML, מונחון Power BI או מנגנון הבנייה של שבועות הקורס.
- חובת שימוש במודל מסוים או בתהליך Multi-Agent מורכב.

מטרתה לעזור למורה **להישאר בעל ההחלטות המקצועיות**, בלי להפוך לבודק של מאות תוצרים שנוצרו בבת אחת.
