# כיווני פיתוח

## כיווני פיתוח מוצעים, שטרם מומשו כמערכת שלמה

| כיוון | מה נרצה לאפשר |
| ---: | ---: |
| העמקת בדיקת המוכנות של המורה | להרחיב את התרגול והשאלונים הקיימים: לבצע משימה, להסביר מדוע, לאבחן טעות ולזהות מה עדיין דורש בירור. |
| הערכה מעצבת של ההוראה | להשוות בין המטרה לבין עבודות התלמידים, להבחין בין סוגי קושי ולבחור שינוי ממוקד לשיעור הבא. |
| מעקב לאורך הקורס | לחבר מטרות, משימות, ראיות, משוב והחלטות הוראה; להבחין בין השלמת משימה לבין הבנה ועצמאות. |
| תחזוקת הידע בפרויקט | לרכז מצב נוכחי והיסטוריית שינויים, ליישב פערים בין גרסאות ולשפר עבודה בין מודלים. |

אפשר להתחיל בניסוי קטן: שיעור אחד, מחוון קצר, כמה עבודות ללא פרטים מזהים ורפלקציה שמובילה לשינוי אחד. ההתבוננות במורה נועדה לפיתוח מקצועי ולבחינת החלטות הוראה; ציוני תלמידים או אחוזי השלמה לבדם אינם מדד לאיכות המורה.
