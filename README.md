# בונים קורס עם בינה מלאכותית — המורה מוביל את הדרך

תשתית למורים ולמפתחי למידה לתכנון קורס, להכנת חומרי הוראה ולשיפורם בעקבות העבודה בכיתה. במאגר נשמרים הנחיות לבינה, שבלונות, החלטות ותוצרים, כדי להמשיך את העבודה בין שיחות ועם מודלי שפה שונים.

התשתית מתפתחת מתוך **קורס <bdi dir="ltr">Power BI</bdi> במגמת מידע ונתונים בתיכון**. אפשר להתחיל מסילבוס או מחומרים קיימים, ולפתח או לשפר רק את החלק שנחוץ כרגע.

## איפה המורה ואיפה הבינה?

| גורם | תפקיד |
| ---: | ---: |
| המורה | מגדיר מטרות ואילוצים, בוחר בין הצעות, מתנסה בחומרים, מלמד ומכריע בהחלטות מקצועיות ובציונים. |
| הבינה | מסייעת לדייק את התכנון, מציעה חלופות, מפתחת ומעדכנת חומרים ומסייעת בבדיקה לפי הנחיות ומחוון שהמורה מאשר. |
| המאגר ב־<bdi dir="ltr">GitHub</bdi> | שומר את ההנחיות, ההחלטות והתוצרים שמשמשים להמשך העבודה. |

המורה והבינה מפתחים יחידה, המורה מתנסה בה ומדייק אותה לפני ההוראה. לאחר השיעור, תצפיות המורה ועבודות התלמידים משמשות לבחירת השיפור הבא.

## מה יש בקורס לדוגמה?

שני כלים אינטראקטיביים מדגימים את העבודה:

- **מסע הכנה למורה:** רקע, התנסות במשימות, צ'קליסט ושאלות לבדיקת המוכנות לשיעור.
- **דוח למידה לתלמיד:** שלבי עבודה, תוצאות צפויות, רמזים ושאלות לבדיקת ההבנה.

<details dir="rtl">
<summary>שימוש חוזר, מגבלות ותודות</summary>

**פרויקט בהתפתחות:** התשתית נבנית מתוך התנסות בהוראה ועדיין ניסיונית. לקורס אחר יש להתאים מטרות, מקורות ותוצרים ולבדוק את התאמתם המקצועית והפדגוגית. לפני שימוש באפליקציות בכיתה יש לבדוק פתיחה, שמירה, הורדות וקישורים לפי [מדריך השימוש](docs/app-usage.md).

**מקורות וזכויות:** נתוני <bdi dir="ltr">Portal</bdi> מופצים ברישיון <bdi dir="ltr">CC0</bdi>. מסמכי המקור של משרד החינוך ו־<bdi dir="ltr">APA</bdi> אינם כלולים כאן; קובצי הלוגו עצמם אינם כלולים. יש לשמור על ייחוס ותנאי השימוש של כל מקור שמוסיפים לקורס.

**תודות וכלים:** הפרויקט פותח בהובלת המורה ובסיוע <bdi dir="ltr">Claude</bdi>, <bdi dir="ltr">ChatGPT</bdi> ו־<bdi dir="ltr">Gemini</bdi>. מערכת העיצוב של מגמת מידע ונתונים שימשה בסיס חזותי, לצד כלי עזר לעיצוב ולעריכה.
