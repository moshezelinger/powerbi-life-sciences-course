# powerbi-life-sciences-course
Open Power BI learning course using life-science data, with interactive student apps, teacher guides, datasets, and reusable templates.


עותק של הפרויקט "קורס Power BI" מ-claude.ai, נכון ל-15.10.2026.

## מבנה

```

  claude/

    סיכום שיחה - בחירת מאגרי נתונים.md
    סיכום שיחה - הכנת השבוע הראשון.md
```

## מאיפה כל קובץ הגיע

| קבצים | מקור | הערה |
| --- | --- | --- |
| שתי האפליקציות, השבלונות, קובצי ה-CSV | הגרסה החיה של הארטיפקט ב-claude.ai, כפי שפורסמה | עדכניות יותר מהעותקים שהיו בתיקיית הפרויקט |
| השקפים (`מצגות/`) | הארטיפקט "שבוע 1: מצגות השיעורים" | אלה קובצי התוכן בלבד. הם מוצגים כמצגת רק בתוך Claude, ובדפדפן רגיל כל שקף נפתח כקטע HTML |
| מדריך המורה, מתווה המצגות, הצ'קליסט | העותקים בפרויקט (Markdown) | ייתכן שהמסמכים החיים ב-Claude Docs נערכו אחרי כן |
| שאר המסמכים | הפרויקט | |

## לפני שמשתפים

- אם המאגר ציבורי, מסמכים רבים כוללים קישורים לארטיפקטים ב-claude.ai. הקישורים עצמם פרטיים.
- מסמכי העיון שהועלו לפרויקט (עקרונות APA ותוכנית הלימודים של משרד החינוך) לא נכללו, כי הם פרסומים של גורמים אחרים.
- נתוני Portal ברישיון CC0, ולכן מותר לפרסם אותם.

## עבודה עם האפליקציות מחוץ ל-Claude

שתי האפליקציות הן קובצי HTML עצמאיים, ונפתחות בכל דפדפן או ב-GitHub Pages. יכולות שתלויות ב-Claude לא יעבדו שם: כפתור "הורדה" של קובצי הנתונים (מחוצה לו מופיעה הודעה שמפנה למודל), ובמסע ההכנה גם השמירה דרך Claude (db, user). לא בדקתי איך מסע ההכנה מתנהג בלעדיהן. הסימונים של התלמידים נשמרים בדפדפן בכל מקרה.
